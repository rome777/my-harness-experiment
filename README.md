# 에이전트 하네스 개선 실험 (my-harness-experiment)

본 저장소는 모두의연구소 **AI Agent 파헤치기** 코스의 **"2. [프로젝트] 에이전트 하네스 톺아보기"** 노드(노드 ID: 6073)의 **"11. 과제 - 도구의 불편을 개선 가설로 바꿔 실험하기"**(스텝 ID: 30747)를 수행하고 제출하기 위한 실험 보고서 및 실행 기록 저장소입니다.

---

## 1. 실험 개요 및 핵심 요약

- **과제명**: 도구의 불편을 개선 가설로 바꿔 실험하기
- **대상 하네스 도구**: Antigravity (Google DeepMind) & Claude Code (Anthropic)
- **핵심 가설**: 에이전트의 단기 세션 컨텍스트(내부 메모리)에 의존하지 않고, 외부 영구 작업 규칙(`AGENTS.md`)과 전 대화 누적 로그(`CHAT_LOG.md`), 그리고 독립 감사 데몬(`auditor_daemon.py`)이라는 **외부화된 하네스 가드레일(Externalized Guardrail & Persistent Memory)**을 적용하면, 장기 연속 작업(100+ 턴)에서도 규칙 위반율을 0%로 통제하고 환각(Hallucination) 발생을 0건으로 차단할 수 있을 것이다.
- **판정 결과**: **가설 지지 (Supported)**
  - 규칙 위반 횟수: 대조군 6회 발생 → 실험군 0회 (100% 억제)
  - 환각(미검증 데이터 날조) 발생: 대조군 2회 발생 → 실험군 0건 (완전 차단)
  - 독립 감사 데몬 검증 통과율: 165개 연속 작업 항목 전수 통과 (100.0%)

---

## 2. 실험 설계 요약 표

| 구분 | 내용 |
|---|---|
| **고정 (통제 변인)** | 모델, 동일 프로젝트 저장소(`pluto`), 동일한 실시간 C++/Python 시스템 벤치마크 태스크 |
| **조작 (조작 변인)** | 외부 영구 작업 규칙(`AGENTS.md`) + 전 대화 누적 로그(`CHAT_LOG.md`) + 독립 감사 데몬(`auditor_daemon.py`) 장착 여부 |
| **이중 측정 (종속 변인)** | 1) 규칙 위반 횟수(한국어 누락, 위험 명령어 호출 등)<br>2) 인게임 데이터 환각(날조 보고) 발생 건수<br>3) 독립 감사 데몬 전수 통과율 |
| **반론 통제** | 추가 가드레일로 인한 토큰 증가 및 추론 지연 반론에 대해, 감사 데몬을 메인 에이전트 루프 외부(백그라운드 비동기 프로세스)로 격리하여 추론 지연 0초 유지 |
| **사전 판정식** | 실험군이 대조군 대비 규칙 위반 횟수를 80% 이상 감소시키고 환각 발생을 0건으로 억제하면 가설 지지, 그렇지 않으면 기각 |

---

## 3. 재검토 조건

1. 에이전트 모델의 유효 컨텍스트 윈도우가 100만 토큰 이상으로 확장되어, 세션 압축(Compaction)이나 인계(Handover) 없이도 초기 시스템 지침을 영구히 유지할 수 있는 경우.
2. 감사 데몬의 사후 검증(Post-execution Audit) 방식을 넘어, 도구 호출 직전에 위험 명령을 가로채 차단하는 Pre-tool Execution Hook이 하네스 레벨에서 완벽히 지원되는 경우.
